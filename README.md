# Machine Learning Based Buyer Segmentation and Investment Profiling

## Project Overview

This project applies machine learning clustering techniques to
identify meaningful buyer segments in the real estate market.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Machine Learning Techniques

- K-Means Clustering
- Hierarchical Clustering
- Elbow Method
- Silhouette Score
- PCA

## Dashboard Features

- Buyer segmentation overview
- Investment behavior analysis
- Financing behavior analysis
- Geographic buyer analysis
- Segment insights
- Interactive filters
- Filtered data download

## Dataset

The project uses a real estate buyer dataset containing
demographic, geographic, acquisition, financing and
satisfaction-related attributes.

## Application

The Streamlit dashboard provides an interactive interface
for exploring buyer segments and investment behavior.
